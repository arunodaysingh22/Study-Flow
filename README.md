# Study Flow

A lightweight student academic planner to organize tasks, schedule study sessions, and track progress.

## Features
- Create and manage study tasks
- Schedule study sessions and reminders
- Track progress and completion status

## Tech
- Python

## Run locally
1. Clone the repo
2. Create a virtual environment: `python -m venv venv`
3. Install dependencies (if any): `pip install -r requirements.txt`
4. Run the main script: `python main.py` (or follow project-specific run instructions)
